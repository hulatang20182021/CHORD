# K=256 Component-guided Item-state Supervision

This revision uses the same consensus / semantic-gap / collaborative-gap / DOCS
ordering as the original release, with **same-view** supervision:

| Input encoder states | Frozen target |
|---|---|
| h1 | PLS consensus |
| h2 | uncompressed semantic prediction gap |
| h3 | uncompressed collaborative prediction gap |
| h1 + h2 | original semantic embedding |
| h1 + h3 | original collaborative embedding |

Each target has its own prediction head and cosine loss. Five unit-weight
objectives are summed before the epoch-dependent auxiliary factor. DOCS has no
auxiliary target. Heads are discarded at inference. This is not the legacy
cross-view PCSC route.

## Protocol

- Frozen tokenizer, three K=256 codebooks, deterministic DOCS suffix.
- T5 backbone: d_model=128, d_ff=1024, four encoder and decoder layers,
  six heads with d_kv=64. Preserve the saved vocabulary and initialization;
  matching architecture alone does not reproduce a historical run.
- AdamW, learning rate 5e-4, weight decay 0.01, warmup ratio 0.01.
- 100-epoch learning-rate and auxiliary schedules, with validation beginning
  at epoch 60, every five epochs, patience three checks.
- Beauty batch 512 / BF16; Instruments and Yelp batch 256 / FP32.
- Reference runs use validation beam20 and test beam20. Later development
  runs use validation beam10 and test beam20; they must be distinguished.
- Full catalog, all test users, no sampled negatives or extra seen-item mask.

Use the shared-anchor training entry point with:

```text
--pcsc_route_control same_view --pcsc_alignment positional --pcsc_h12_mode sum
```

The existing `run_paper_main.sh` remains the legacy K1024 fixed-epoch workflow.
Changing its K alone does **not** reproduce the validation-selected K256 runs.
This update exposes the current loss route; the historical cloud orchestration
is not a portable released training pipeline.

## Reference results

Values below are fractions, evaluated over the full test split. CHORD entries
are seed42, not the two-run means in the manuscript's main table.

| Beauty model | HR@5 | HR@10 | NDCG@5 | NDCG@10 |
|---|---:|---:|---:|---:|
| CHORD CE | 0.04512 | 0.07190 | 0.02901 | 0.03770 |
| CHORD component-only | 0.05102 | 0.08098 | 0.03369 | 0.04334 |
| CHORD combination-only | 0.04664 | 0.07481 | 0.03061 | 0.03971 |
| CHORD CIS | 0.05133 | 0.08121 | 0.03433 | 0.04400 |
| TIGER SID + CHORD same-source CIS | 0.05048518 | 0.07771766 | 0.03438505 | 0.04312645 |

The last run completed on 2026-10-26, seed42, 22,363 users, validation beam10 /
test beam20. It retains TIGER SIDs but uses CHORD's continuous supervision
targets. No new paired CE run was trained, so comparison with a historical CE
result is descriptive, not a new controlled treatment effect.

The diagnostics establish associations, not causal mediation. Gap and Full-view
tokenizers have nearly identical recommendation accuracy in the current
comparison; the results do not establish the necessity of prediction gaps.
